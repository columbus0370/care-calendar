# 介護サービス希望カレンダー

ケアマネさんへの予定共有ツール

## 📱 インストール方法

### スマホでアクセス

**以下のURLにスマホのブラウザでアクセス：**

https://columbus0370.github.io/care-calendar/

### Android スマートフォン
1. 上記URLをブラウザで開く
2. ブラウザメニュー（右上 ⋮）→「ホーム画面に追加」
3. アプリがホーム画面に追加される
4. インターネット接続なしでも動作

### iPhone（Safari）
1. 上記URLを開く
2. 下部の共有ボタン（↑）→「ホーム画面に追加」
3. アプリがホーム画面に追加される

## ✨ 機能

- 📅 月ごとのカレンダー入力
- 🎨 サービス種別の色分け表示
- 🖼️ 月ごとの画像ダウンロード
- 📋 テキスト形式での出力
- 🔄 オフライン対応

## 操作方法

- 日付をタップ → サービス・終了日・備考を入力

## 技術

- React 18
- PWA（Progressive Web App）
- Service Worker（オフライン対応）
- Canvas API（画像生成）
